# 大六壬排盘解卦 Skill

中国古代最高级术数之一——**大六壬**，号称"人事之学"。本 skill 实现大六壬完整排盘：月将加时、四课三传、天将排布、神煞查询、九宗门起法、毕法赋断语。

## 快速开始

### 运行排盘

```bash
python3 scripts/liuren.py -q "用户的问题" [-y 年] [-m 月] [-d 日] [-H 时] [--json]
```

**参数说明：**
- `-q`：求测问题（选填，用于上下文分析）
- `-y/-m/-d`：年月日，不填则用当前时间
- `-H`：时辰（0-23点），不填则用当前时间
- `--json`：JSON格式输出（程序化处理）

**示例：**
```bash
# 当前时间起课
python3 scripts/liuren.py -q "最近财运如何"

# 指定时间
python3 scripts/liuren.py -q "这桩婚事能成吗" -y 2026 -m 4 -d 19 -H 16

# JSON输出（供Agent二次分析）
python3 scripts/liuren.py --json -y 2026 -m 4 -d 19 -H 16
```

## 核心概念速查

### 十二月将（太阳过宫，以中气为换将节点）

> 月将即太阳躔次，随太阳在黄道十二宫运行而定。**以中气为换将节点**（非节/月建切换）。
> 月将 = 月支逆数（寅→亥、卯→戌、辰→酉……斗柄与太阳成六合）
> ⚠️ 月建按"节"切换（立春、惊蛰……），月将按"中气"切换（雨水、春分……），两者差约15天

| 月份 | 月支 | 月将 | 别称 | 中气后启用 |
|------|------|------|------|-----------|
| 正月 | 寅 | 亥 | 登明 | 雨水后 |
| 二月 | 卯 | 戌 | 河魁 | 春分后 |
| 三月 | 辰 | 酉 | 从魁 | 谷雨后 |
| 四月 | 巳 | 申 | 传送 | 小满后 |
| 五月 | 午 | 未 | 小吉 | 夏至后 |
| 六月 | 未 | 午 | 胜光 | 大暑后 |
| 七月 | 申 | 巳 | 太乙 | 处暑后 |
| 八月 | 酉 | 辰 | 天罡 | 秋分后 |
| 九月 | 戌 | 卯 | 太冲 | 霜降后 |
| 十月 | 亥 | 寅 | 功曹 | 小雪后 |
| 冬月 | 子 | 丑 | 大吉 | 冬至后 |
| 腊月 | 丑 | 子 | 神后 | 大寒后 |

> ⚠️ 每年约一半日子月将与月建不在六合关系——拿月柱地支反推月将会出错。月将只由中气定。

### 昼夜分界与天将顺逆

- **昼夜分界**：卯辰巳午未申为昼，酉戌亥子丑寅为夜
- **天将排列**：贵人→螣蛇→朱雀→六合→勾陈→青龙→天空→白虎→太常→玄武→太阴→天后
- **天将乘天盘支**（不是地盘宫）
- **顺逆规则**：贵人所临**地盘宫**在亥子丑寅卯辰→顺布；在巳午未申酉戌→逆布

### 九宗门起法（核心判定链）

> **判定链**：伏吟 → 返吟 → 八专 → 别责 → 贼克/比用/涉害 → 遥克 → 昴星
> ⚠️ 列举次序（贼克→比用→涉害→遥克→昴星→别责→八专→伏吟→返吟）是教材目录，不是判定顺序
> 详见 `references/jiu-zong-men.md`

| 起法 | 触发条件 | 取用规则 |
|------|----------|----------|
| **伏吟法** | 月将与占时同支（天地盘重合） | 阳日取干上神、阴日取支上神；中末传取刑 |
| **贼克法** | 四课上下神有五行相克 | 下贼上优先于上克下；恰一课定初传 |
| **比用法** | 贼克后候选多于一个 | 取上神阴阳与日干相同者 |
| **涉害法** | 比用后仍不止一个 | 数深浅（历经地支克我者个数），深者发用；相等取孟仲季 |
| **返吟法** | 月将与占时相冲 | 有克回落贼克法；无克取驿马为初传 |
| **八专法** | 日干寄宫与日支同支，无克 | 阳日顺数三神，阴日逆数三神 |
| **别责法** | 四课只剩三课，无克 | 阳日取五合干寄宫上神；阴日取日支三合顺行第四位（同局下一位） |
| **遥克法** | 四课齐备无克，不落上述门 | 先取克日干者，没有才取日干克者 |
| **昴星法** | 判定链末端（恒有解） | 阳日取地盘酉上神；阴日取天盘酉所临地盘神 |

### 三传生克关系

| 关系 | 含义 | 吉凶倾向 |
|------|------|----------|
| **初传生日干** | 事端由外而来，有生扶 | 吉 |
| **初传克日干** | 事端主动来克，主凶 | 凶 |
| **日干生初传** | 我主动付出，耗散 | 凶 |
| **日干克初传** | 我能制服事端 | 吉 |
| **中传为病** | 过程阻碍 | 凶 |
| **中传为药** | 过程有救应 | 吉 |
| **末传生日干** | 结果有回馈 | 吉 |
| **末传克日干** | 结果不利 | 凶 |

## 断卦方法论

### 一、总原则

> **贵神为主，三传为凭，天将为辅，神煞为证。**

### 二、分步断卦法

#### Step 1: 看课体阴阳贵贱
- 阳日阴时 / 阴日阳时 → 顺治/逆治
- 日贵/时贵 / 日时不贵
- 决定课体格局高低

#### Step 2: 定三传动静
- 初传动 → 事端发动快
- 中传动 → 过程波折
- 末传动 → 结果延迟
- 三传俱静 → 事端难成

#### Step 3: 查生克制化
- 传干生日干 → 有贵人相助
- 传干克日干 → 有小人阻挠
- 日干克传干 → 我能掌控
- 比和作用 → 朋友同辈

#### Step 4: 观天将叠加
- 贵人临初传 → 贵人主动相助
- 青龙临末传 → 结果获财喜庆
- 白虎临中传 → 过程有病灾
- 玄武临末传 → 结果失物被骗

#### Step 5: 证神煞应验
- 天乙贵人临日/时 → 贵人扶持
- 驿马临初传 → 远行/变动快
- 桃花临日/时 → 桃色/人缘
- 文昌临朱雀 → 文书考试利

#### Step 6: 定应期
- 初传应时/日、中传应月、末传应年
- 驿马动 → 应期快
- 空亡填实 → 应期到
- 值符值使方位 → 方位应期

### 三、常见场景断卦模板

#### 问事业仕途
```
看：贵人（贵人扶助）+ 朱雀（文书官职）+ 初传（事端发动）
贵人临初传/日干 → 有贵人提拔，升迁可期
朱雀临贵人/青龙 → 文书有喜，公文顺遂
初传生日干/比和 → 外力推动，顺水推舟
破局：若初传克日且白虎/勾陈临之 → 阻碍大，宜守不宜进
```

#### 问财运求财
```
看：勾陈（田宅财物）+ 白虎（金钱数目）+ 末传（最终结果）
勾陈临末传生日 → 稳健获财，房产增值
青龙临勾陈/末传 → 横财/意外之财
白虎临末传克日 → 破财损耗，防投资失误
破局：找生日干的传干方位行事
```

#### 问婚姻感情
```
看：六合（和合）+ 天后（女方）+ 日干/日支（男女双方）
六合临日干/日支 → 婚姻和合，易成
天后临日干生扶 → 女方主动/有利女方
日干生日支/比和 → 男女和谐
破局：玄武/太阴临六合/天后 → 隐私/第三者/不诚实
```

#### 问疾病健康
```
看：玄武（隐病）+ 勾陈（病根）+ 末传（病情结果）
玄武临日支/初传 → 隐疾/难查明病因
勾陈临末传 → 病根深，久治不愈
白虎临勾陈/末传 → 病势凶险，防手术/血光
破局：贵人/青龙临末传生日 → 有贵人良医相救
```

## 注意事项

1. **一事不二占**：同一件事不宜反复起课
2. **时辰精确**：大六壬对时辰极敏感，差一时辰完全不同课
3. **月将以中气为界**：非节气交接日勿用交接月将
4. **农历准确**：必须用精确农历（置闰月），公历转农历有误差
5. **不妄言生死**：涉及重大凶险时，强调仅供参考
6. **心存正念**：大六壬本为决策辅助，不可用于害人
7. **理性看待**：术数是参考工具，决策还需理性判断
