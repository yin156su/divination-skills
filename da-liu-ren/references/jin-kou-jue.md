# 大六壬·金口诀快速起课法

> 修正记录：四位定位原写法（日干/时干/月支/日支）有误，已按传世《六壬神课金口诀》（TK172/官板系统）原文校正。该来源的版本辨正见 `chutu-wenxian.md` 第三节。

金口诀是大六壬的快速简化起课法，适合应急占验、快速断卦。

## 四位定位

金口诀以"四位"成课，自下而上排列：

| 位 | 取法 | 含义 | 主客 |
|----|------|------|------|
| **地分** | 现场方位（面朝方向）或远程约定方位 | 事体方位、落地归处 | 客/地 |
| **将神** | 月将加时，落到地分上所得地支 | 过程、中介、方法 | 主/将 |
| **贵神** | 昼夜贵人（按日干定），顺逆布到地分 | 贵人、外力、助力 | 主/神 |
| **人元** | 五子元遁，从贵神天干起遁到地分所得天干 | 事主自身、发端 | 客/人 |

> ⚠️ 校正说明：旧版将四位定位为 日干/时干/月支/日支，这是错误的。传世原文的起法是：
> 1. 先定地分（方位）
> 2. 月将加时→将神
> 3. 昼夜贵人→贵神
> 4. 五子元遁→人元
> 五位次序与取法可参《大六壬神课金口诀》（TK172/官板系统，见 `chutu-wenxian.md` 第三节）。

## 使用方式

```bash
# 快速起课
python3 scripts/jinkoujue.py -q "问题" [-y 年] [-m 月] [-d 日] [-H 时] [--json]
```

## 四位生克断

判断四位对日干的生克：
- 生我者（生日干）→ 吉，有助力
- 克我者（克日干）→ 凶，有阻碍
- 我生者（我生之）→ 泄耗，付出
- 比和 → 平，朋友同辈

## 简断规则

- 四位多吉（生/比和 ≥ 3）→ 事端顺遂，可速决
- 吉多凶少 → 宜主动把握
- 吉凶相当 → 宜守伺机
- 四位多凶 → 事端阻滞，宜缓守

## 十二神将落宫

以人元为起点，顺排十二地支，得十二神将落宫，辅助判断吉凶位置。

## 判断要点

1. 金口诀是简化法，快速但精度略低于完整排盘
2. 适合应急、日常小事占验
3. 完整排盘（`liuren.py`）用于重大或复杂问题
4. 四位生克 + 神将吉凶综合判断

> 金口诀简便快捷，但断卦精度有限，重要决策建议用完整排盘。
