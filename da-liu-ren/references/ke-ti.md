# 大六壬·课体分类速查

课体由四课三传组合而成，反映事端整体格局。判断课体是断卦第一步。

## 常见课体分类

### 以三传起法分（九宗门对应的课体）

| 课体 | 三传特征 | 主断 |
|------|----------|------|
| 贼克课 | 有上神克日干，取克神为初传 | 事端由外力推动，主动来犯 |
| 比用课 | 两课俱克日干，取比和者 | 朋友同辈相助，宜合伙 |
| 涉害课 | 日干支同类，上神害日干 | 自招其祸，宜自省退守 |
| 遥克课 | 日干支遥相克 | 事端远隔，信息不通 |
| 昴星课 | 日干支同宫（寅申巳亥） | 文书、考试、公文有应 |
| 别责课 | 日干支同宫（子午卯酉/辰戌丑未） | 分离、变动、异地 |
| 八专课 | 纯阴/纯阳，四课无贼克 | 孤立无援，独断 |
| 伏吟课 | 上神与日干支相同 | 重复、迟缓、旧事重提 |
| 反吟课 | 上神冲日干支 | 反复、变动、百事皆空 |

### 以阴阳贵贱分

| 课体 | 条件 | 主断 |
|------|------|------|
| 阳课 | 阳日阳时，顺治 | 事态明朗，主动进取 |
| 阴课 | 阴日阴时，逆治 | 事态隐晦，宜守 |
| 顺治课 | 日贵在时上 | 顺理成章 |
| 逆治课 | 日贵在时下 | 事有阻碍 |

### 特殊课体

| 课体 | 特征 | 主断 |
|------|------|------|
| 三元课 | 干支同类且上神同类 | 格局高贵，主贵 |
| 专旺课 | 一神独旺 | 专一之力，可成大事 |
| 重审课 | 三传生克互见 | 事有反复，需审慎 |
| 连茹课 | 三传相生连绵 | 事端连续，绵延不断 |

## 课体判断要点

1. 先看阴阳（日干/日支阴阳）、顺逆（贵神顺逆布）
2. 再看三传动静（初中末）
3. 后看生克制化（传干与日干关系）
4. 课体是"骨架"，需结合天将、神煞综合判断

> 注意：课体判断需准确，同一课盘可能兼具多课特征，取最显著者为断。
