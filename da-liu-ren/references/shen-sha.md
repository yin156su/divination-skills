# 大六壬·神煞大全

神煞是补充课盘判断的重要参考，"天将为辅，神煞为证"。

## 核心神煞

| 神煞 | 查找法 | 吉凶 | 含义 |
|------|--------|------|------|
| 天乙贵人 | 甲戊庚牛羊，乙己鼠猴乡 | 吉 | 贵人扶助、逢凶化吉 |
| 驿马 | 申子辰马在寅，寅午戌马在申 | 吉 | 远行、变动、奔波 |
| 桃花 | 申子辰在酉，寅午戌在卯 | 凶 | 桃色、人缘、酒色 |
| 文昌 | 甲巳、乙午、丙戊申等 | 吉 | 考试、文书、学业 |
| 华盖 | 申子辰在辰，寅午戌在戌 | 平 | 孤独、清修、宗教 |
| 劫煞 | 申子辰在巳，寅午戌在亥 | 凶 | 破财、被骗、抢劫 |
| 灾煞 | 申子辰在午，寅午戌在子 | 凶 | 意外灾祸、车祸 |
| 岁破 | 与流年地支相冲 | 凶 | 年运不利、诸事不宜 |

## 神煞落位判断

- 天乙贵人临日/时 → 贵人扶持
- 驿马临初传 → 远行/变动快
- 桃花临日/时 → 桃色/人缘
- 文昌临朱雀 → 文书考试利
- 华盖临身 → 孤独清修、宜独处
- 劫煞临身 → 破财损耗
- 灾煞临身 → 意外灾祸
- 岁破临身 → 年运不利

## 神煞应期

- 驿马动 → 应期快
- 空亡填实 → 应期到
- 神煞旺相之时为应期

## 判断要点

1. 神煞是"验证符号"，印证课体、三传、天将的判断
2. 多个凶煞同现 → 凶性加强
3. 吉煞临凶位、凶煞临吉位需辩证
4. 神煞落于三传/日干支的不同位置，吉凶侧重不同

> 神煞多达数十种，此处收录核心常用者。判断时以课体、三传为主，神煞为辅，不可喧宾夺主。
