# 大六壬·三传生克详解

三传（初传、中传、末传）代表事端从发动到发展的三个过程阶段。

## 三传基本含义

| 传 | 代表 | 位置 |
|----|------|------|
| 初传 | 事端发动、起因、开端 | 第一个传 |
| 中传 | 过程、中间变化、阻碍 | 第二个传 |
| 末传 | 结果、最终结局 | 第三个传 |

## 三传与日干生克吉凶

| 关系 | 含义 | 吉凶倾向 |
|------|------|----------|
| **初传生日干** | 事端由外而来，有生扶 | 吉 |
| **初传克日干** | 事端主动来克，主凶 | 凶 |
| **日干生初传** | 我主动付出，耗散 | 凶 |
| **日干克初传** | 我能制服事端 | 吉 |
| **中传为病** | 过程阻碍 | 凶 |
| **中传为药** | 过程有救应 | 吉 |
| **末传生日干** | 结果有回馈 | 吉 |
| **末传克日干** | 结果不利 | 凶 |

## 三传动静

| 情况 | 含义 |
|------|------|
| 初传动 | 事端发动快 |
| 中传动 | 过程波折 |
| 末传动 | 结果延迟 |
| 三传俱静 | 事端难成 |

## 病药理论

- **病**：三传中克日干之传为病，是事端中的阻碍、病灶
- **药**：三传中生日干之传为药，是转机、救应
- 病多药少 → 事难成；药多病少 → 事可成
- 若中传为药，虽初传凶，中途有救

## 判断要诀

1. 初传定事端性质，看其与日干生克
2. 中传定过程难易，看是否为病药
3. 末传定最终结果，看其吉凶旺衰
4. 三传相生为顺，相克为逆
5. 结合天将落位，判断具体人事
