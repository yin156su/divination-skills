# 大六壬·毕法赋断语集成

《毕法赋》是大六壬断卦的经典口诀集，本 skill 的 `bifa_fu.py` 已收录核心断语并自动匹配。

## 使用方式

```bash
# 自动匹配课盘，输出匹配的毕法赋断语
python3 scripts/bifa_fu.py -y 2026 -m 4 -d 19 -H 16

# JSON 输出
python3 scripts/bifa_fu.py --json -y 2026 -m 4 -d 19 -H 16
```

## 断语分类

脚本收录的毕法赋按以下类别组织：
- **课体总论**：九宗门起法对应的总断
- **三传生克**：初中末传与日干生克的吉凶
- **天将叠加**：天将临三传位置的吉凶
- **神煞应验**：核心神煞命中的应验
- **旬空应期**：空亡相关的应期判断
- **求财/婚姻/官非/疾病/失物/出行/考试断验**：具体事类断语

## 匹配机制

`bifa_fu.py` 自动从 `liuren.py` 生成的图表数据中提取特征：
- 九宗门类型（`jiu_zong_men`）
- 课体类型（`ke_ti_type`）
- 三传生克关系（`san_chuan_rel`）
- 天将临三传（`jiang_at`）
- 神煞命中（`shen_sha`）
- 空亡（`kong_wang`）

## 判断要点

1. 毕法赋是"口诀印证"，辅助断卦而非独立依据
2. 匹配的断语需结合具体课盘辩证解读
3. 多条断语同时命中时，优先级高的（如大吉/大凶）优先考虑
4. 毕法赋断语需与课体、三传、天将、神煞综合判断
