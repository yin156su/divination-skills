# 大六壬·十二天将深度解析

十二天将代表人事的吉凶神煞，叠加在三传/四课之上辅助断卦。

| 天将 | 吉凶 | 含义 | 主管事项 |
|------|------|------|----------|
| 贵人 | 大吉 | 贵人扶助、化凶为吉 | 官职、求人、贵人 |
| 腾蛇 | 凶 | 虚惊、怪异、缠绕 | 惊恐、怪病、虚诈 |
| 朱雀 | 半凶 | 口舌、文书、是非 | 文书、口舌、喜庆 |
| 六合 | 吉 | 和合、婚姻、合伙 | 婚姻、合作、和解 |
| 勾陈 | 凶 | 争斗、田宅、拘禁 | 田宅、官非、疾病 |
| 青龙 | 大吉 | 喜庆、财帛、生旺 | 财运、喜庆、生育 |
| 天空 | 凶 | 虚诈、欺骗、落空 | 虚假、欺诈、失望 |
| 白虎 | 大凶 | 凶丧、疾病、血光 | 疾病、丧葬、伤灾 |

## 天将临三传

| 临位 | 吉将 | 凶将 |
|------|------|------|
| 临初传 | 贵人主动相助 | 腾蛇虚惊、朱雀口舌 |
| 临中传 | 太常喜庆 | 白虎病灾、勾陈田宅争 |
| 临末传 | 青龙获财、六合和合 | 玄武失物、天空落空 |

## 天将组合效应

| 组合 | 含义 |
|------|------|
| 玄武+六合 | 私情暗昧、婚外情 |
| 朱雀+勾陈 | 口舌官非、诉讼 |
| 白虎+玄武 | 病重难医、凶险 |
| 贵人+青龙 | 大贵大吉 |
| 天空+天后 | 虚花不实、文书落空 |

## 天将生克（相对日干）

- 天将地支生日干 → 有贵人相助（吉）
- 天将地支克日干 → 有小人阻挠（凶）
- 日干克天将 → 我能掌控（吉）
- 比和 → 朋友同辈（平）

## 判断要点

1. 天将是"人事符号"，须结合三传位置断
2. 看天将落三传的哪个位置，判断吉凶发生在哪个阶段
3. 天将组合效应能揭示隐藏关系（如私情、官非）
4. 吉将落凶位、凶将落吉位需辩证看待
