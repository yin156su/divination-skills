# 奇门遁甲·应期与破局详解

## 应期判断

### 主要方法
1. **值符值使落宫数字**：值符/值使落宫的数字为应期天数/年数
2. **马星主快**：用神宫临马星（值符、腾蛇等）主事快
3. **空亡填实**：空亡之事，逢冲（冲起空亡）之时为应期
4. **用神旺相**：用神旺相之时为应期

### 应期判断要点
- 阳遁顺推，阴遁逆推
- 应期以时辰、日、月、年为单位，看用神旺衰快慢
- 空亡逢冲（合/冲空亡地支）为应期到

## 5大破局策略

### 1. 吉多进取
- 全盘多吉格、用神生旺 → 主动出击
- 抓住时机，乘势而为

### 2. 凶多固守
- 全盘多凶格、用神受克 → 固守待变
- 暂缓大动作，避免冲动

### 3. 伺机而动
- 吉凶相当 → 观望，寻找时机
- 等马星动、空亡填实时再行动

### 4. 借势破局
- 用神逢凶，找用神宫的三合宫位/生旺方位救应
- 向吉门吉星方位行事，借势化解

### 5. 避凶趋吉
- 避开凶门、凶格、凶时、凶方位
- 选择吉门（开、休、生）落宫方位行事

## 分场景破局模板

| 场景 | 破局方向 |
|------|----------|
| 事业 | 找开门三合宫位救应，向开门生旺方位进取 |
| 财运 | 找生门生旺方位行事，避免死门方位 |
| 感情 | 看乙奇与庚的关系，择六合旺相之时 |
| 健康 | 天芮克何宫即何脏腑问题，就医择天心/天辅方位 |
| 官非 | 避开惊门方位，择开门贵人方位 |

> 破局本质是"借吉避凶"，用吉门吉星吉方化解凶格，属传统术数决策辅助，需理性对待。
