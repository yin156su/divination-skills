# 奇门遁甲·用神取用大全

根据所问之事取对应用神，是用神落宫分析吉凶的关键。

|------|------|----------|
| 事业/工作 | 开门、值符、天心 | 值使落宫、开门状态 |
| 财运/投资 | 生门、戊、天芮 | 生门落宫、戊所在宫 |
| 婚姻/感情 | 休门、乙奇、六合 | 休门落宫、乙奇状态 |

| 出行/旅游 | 马星、腾蛇、玄武 | 所去方向宫位吉凶 |
| 失物/寻人 | 天芮、杜门 | 落宫状态+空亡 |

## 用神空亡论

- 用神落空亡：代表"没有"、"不实"、"求不得"、"人不在"
- 空亡主减力，吉事不成，凶事减凶
- 空亡逢冲（马星/值符冲）则填实，应期到
- 用神临马星主快、主变动

## 判断步骤

1. 根据问题定用神
2. 看用神落宫的：门、神、格、星
3. 看是否空亡、入墓
4. 看用神宫与值符宫、问事人年命的生克
5. 综合定应期
