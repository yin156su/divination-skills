# 奇门遁甲·八门五行生克关系

八门代表人事动向，判断落宫吉凶的核心之一。

## 八门应事

| 门 | 五行 | 吉凶 | 应事 |
|----|------|------|------|
| 开门 | 金 | 吉 | 事业、开启、通达、贵人 |
| 休门 | 水 | 吉 | 休息、和缓、洽谈、求财 |
| 生门 | 土 | 大吉 | 生机、财运、房产、谋利 |
| 伤门 | 木 | 凶 | 伤害、争斗、捕猎 |
| 杜门 | 木 | 平 | 隐藏、阻塞、技术 |
| 景门 | 火 | 平 | 文书、声名、谋划 |
| 死门 | 土 | 凶 | 死亡、终结、地产 |
| 惊门 | 金 | 凶 | 惊恐、诉讼、口舌 |

## 八门五行生克

- 开门（金）与惊门（金）同五行
- 休门（水）生开门、惊门（金）
- 生门（土）克休门（水）
- 伤门、杜门（木）克生门、死门（土）

判断门与宫、门与用神的生克：
- 门生宫、宫生门 → 吉
- 门克宫、宫克门 → 凶
- 比和 → 平

## 八门入墓

- 门入墓（落五行墓库之宫）→ 力量被困，主阻塞
- 开、休、生门入墓 → 吉门受阻，事难成
- 死、惊、伤门入墓 → 凶门受制，凶性减轻

## 八门伏吟

- 门伏吟（门落本位宫）→ 停滞、重复、迟缓
- 主事端难进，守成可守
- 开门伏吟 → 事业停滞
- 生门伏吟 → 财路不畅
